Domain join for Windows 10 and 11. PCs join the domain with the DNS SRV records Windows looks for, Kerberos and NTLM sign-in, password policy and lockout. People, groups, computers and OUs live in a quiet, text-first app, with a labdc command line for scripts.

Features

What it does

LDAP, LDAPS and Global Catalog

Query the directory the way an application would, over LDAP, LDAPS or the Global Catalog, alongside CLDAP, SMB and secure dynamic DNS updates.

Terminal — LDAPS query
$ ldapsearch -H ldaps://dc1.corp.example \ -b dc=corp,dc=example (sAMAccountName=alex) dn: CN=Alex Chan,OU=Engineering,DC=corp,DC=example cn: Alex Chan memberOf: CN=Wi-Fi Users,OU=Groups memberOf: CN=Engineering,OU=Groups result: 0 Success

Install

Get started in a minute

macOS

  1. Unzip the download and drag LabDC.app into Applications.
  2. The build is not notarized. On first launch, right-click the app, choose Open, then confirm.
  3. Or run once in Terminal: xattr -dr com.apple.quarantine /Applications/LabDC.app
  4. Requires macOS 26 or later · Apple Silicon.
